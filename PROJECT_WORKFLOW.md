# Databricks Data Analyst Practice

## Branch Workflow

- dev: Develop SQL queries and notebooks.
- stage: Test and validate changes.
- prod: Maintain the approved release version.
- master: Maintain the stable final version.

## Project Objectives

- Practice Databricks SQL.
- Analyze customers, orders, products, and stores.
- Build KPIs and dashboard queries.
- Track changes using Git and GitHub.
